# ADR-005: 학부대학(hakbu) 게시판 개편 대응 — hakbu 단일 복구 + 포털연동 슬라이스 폐기

- **상태**: 채택됨 (2026-07-29 최초, 2026-07-30 콘텐츠 실측 후 개정 — 포털 슬라이스 폐기 확정)
- **관련**: `docs/known-issues.md` §8(sls/success 동일 부류 개편)·§10(본 건 발견·해결 기록), `docs/missing-departments.md` §4(기존 보류 결정)

## 맥락

hakbu.skku.edu가 §8과 같은 CMS 개편(`/community/` 경로 제거)으로 `hakbu` + `hakbu-portal*` 9개 소스가 404 침묵 중단됨 (crawl_health 알림으로 감지). 라이브 조사 결과:

- 새 게시판: `/hakbu/notice.do`(나브 "공지사항") · `/hakbu/notice_total.do`(나브 "통합공지", 구 `boardId` 138880~138886 필터 유효, 신규 138879=학사 존재).
- 리스트·첨부 셀렉터 전부 호환. 상세 content는 §8 부류와 동일하게 코드 fallback(`div.board-view-content-wrap`)이 처리 (success/sls도 현재 이 경로로 운용 중).
- 상세 링크가 `articleNo=` → `viewBoardId=...&itemId=...` 체계로 변경. itemId는 **숫자**(2025-06 이후 신규 글 전부)와 **32자리 hex UNID**(2019~2025-05 레거시 글, 구 시스템 마이그레이션 잔재)가 혼재. 기존 파서 `itemId=(\d+)`는 hex가 숫자로 시작하면(`75E2...` → `75`) **잘못된 articleNo를 추출**하는 버그 보유.
- prod DB에 hakbu 계열 문서 **0건** (9개 소스는 §7 필터 인시던트와 개편 시점이 겹쳐 한 번도 성공 적재된 적 없음) → sourceUrl/dedup 마이그레이션 이슈 자체가 없음.

**콘텐츠 실측 (2026-07-30, 결정 개정의 근거)** — 보드별 최근 50건 목록 + 상세 본문 표본 판독:

- `notice.do`(공지사항): 최근 50건 중 44건 작성자가 "학부대학". 신입생 직권배정·학점취득특별시험(응시대상: 신입생)·계열별 성적우수장학금("학과진입" 전후 구분 안내) 등 **계열제 학생 전용 공지** — 포털에 없는 대체 불가 콘텐츠.
- `notice_total.do`(통합공지) 슬라이스: 작성자가 교무팀·학생지원팀·학생인재개발팀·학생성공센터 등 본부 부서, 내용은 대학원 논문·전교 취업 프로그램·SW 라이선스 등 **전교 대상**. 표본 제목 DB 대조 결과 동일 글이 이미 `skku-main`/`skku-notice02~07`에 크롤돼 있음 (예: "기수료자 논문대체 학점취득제" 7개 소스 중복) — 대학 포털 공지의 CMS 신디케이션 미러이며 학부대학 큐레이션이 아님. 입학(현행 3건, 최신 2025-11)·장학(2건, 2025-11) 슬라이스는 사실상 휴면.

## 결정

1. **`hakbu` 단일 유지 + baseUrl 리맵**: `hakbu` → `https://hakbu.skku.edu/hakbu/notice.do` (name "학부대학(계열제)" 유지 — 학부대학은 계열제 입학생 담당 기관이므로 독자 기준 명칭이 정확함). 나머지 필드 무변경.
2. **`hakbu-portal` + 슬라이스 7개 = 8개 엔트리를 sources.json에서 삭제**: 포털 공지 미러라 `skku-notice*`와 완전 중복. cheme/nano식 excludeReason 은퇴가 아닌 삭제인 이유 — 실데이터 0건·앱 노출 이력 0인 투기적 엔트리라 사용자 접점이 없고, 은퇴 플래그는 앱 픽커에 회색 항목 8개만 남김. categories.json 참조 없음 확인.
3. **레거시 hex UNID 글은 의도적으로 skip**: ID 추출 정규식에 negative lookahead(`(?![0-9A-Za-z])`)를 추가해 부분 매칭 오추출을 차단하고, hex UNID 행은 debug 로그(`legacy_unid_item_skipped`)로만 기록.

## 근거

| 후보 | 판단 |
|------|------|
| ① 9개 전부 1:1 리맵 + hex skip (최초 채택 → 개정으로 축소) | URL만 보고 구조 보존이 안전하다고 판단했으나, 콘텐츠 실측에서 포털 슬라이스가 중복·휴면임이 확인돼 유지 근거 소멸. 유지 시 요약 모듈이 중복 글을 소스별로 재요약(AI 비용)하고 픽커에 빈 피드 노출 |
| ② hex UNID 지원 (해시 → int64 articleNo) | `articleNo: int` 스키마 전제를 해시로 우회하는 해킹. 얻는 것은 1년 이상 지난 아카이브뿐 (기각) |
| **③ hakbu만 유지, 포털연동 계열 폐기 (최종 채택)** | `missing-departments.md` §4에서 "역할 중복 가능 — 추후 결정"으로 보류돼 있던 항목을 실측 근거로 확정. 학부대학 탭 가치는 `hakbu` 자체 공지가 전담, 포털 공지는 이미 성균관대_통합 소스로 앱에 존재 |

## 재검토 조건

- `hakbu` 피드에서 **최근 글 누락** 리포트 발생 → 신규 글이 hex UNID로 발급되기 시작했는지 확인 (skip 정책 재평가 = 후보 ② 재개봉)
- 학부대학 사이트가 포털 미러가 아닌 **자체 큐레이션 보드**를 신설하면 해당 보드만 신규 소스로 추가 (삭제된 8개의 boardId 매핑은 본 ADR §맥락에 보존)
- 다른 skku-standard 소스가 같은 `viewBoardId/itemId` 체계로 개편되면 이 ADR의 정규식·skip 정책이 그대로 적용되는지 확인
